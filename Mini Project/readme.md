Reflection:

I chose to modify the Flappy Bird template because it is a game I frequently played as a child, unlike Pong. Additionally, I have also played it in modified forms before, such as My Boo Flappy Bird, so I was really interested in changing it to fit my interests. In this case, classic literature is a hobby I feel connects my family across the world. The main logic implemented was the Game State, Bird & Pipe classes, Collision Detection, and User input. The program needed to recognise when the user was interacting with the game, so that the movement of the character reacted smoothly. Defining the bird and pipe classes ensured that when the birds collided with the pipes, it knew to change the game state. Making sure that the gameplay felt similar to the original game. Every time the user flies through the walls without touching them, the score increments by 1. However, if they hit a wall, they instantly die and are taken to the game-over screen. One aspect I should have changed was ensuring that if the user collides with the bottom of the screen, it would end the game. Currently, the character rests there. For this project, I chose the theme Alice in Wonderland, except instead of falling down the rabbit hole, she must fly through a Flappy Bird-style obstacle course. Therefore, I chose background music from Tim Burton’s 2010 Alice in Wonderland movie. The track changed based on which scene the user was looking at. The more dramatic music played while the user was actively playing, emphasising the fast-paced gameplay. Additionally, I used his font to make all the UI elements cohesive. The most challenging aspect was changing the appearance of the walls. Initially, I wanted to use a repeating block-style pattern with different objects from the story on them. This would randomly place them and make the walls appear different each time the user flew. However, this was difficult to implement, so I ended up just putting a brick pattern on the walls.
